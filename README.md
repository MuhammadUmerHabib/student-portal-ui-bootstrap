🎓 Student Portal UI

A multi-page student management portal UI built with
HTML5, Bootstrap 5 and JavaScript.

Features
- Responsive Bootstrap layout
- Student dashboard
- Dynamic student card generation
- JavaScript DOM manipulation
- Dynamic card creation
- Bootstrap components
- Student details page
- Student filtering UI
- Login UI
- Static demo data

JavaScript Implementation
- document.getElementById()
- document.createElement()
- setAttribute()
- appendChild()
- for loop
- Dynamic IDs
- DOM manipulation

This is a frontend learning project.
There is currently no backend or database.
Student information is demo/static data.
