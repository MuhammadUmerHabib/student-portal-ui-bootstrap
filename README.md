# 🎓 Student Portal UI Template

A multi-page, front-end layout designed for a student management system. This project is built entirely utilizing **HTML5** and **Bootstrap 5**, focusing heavily on UI components, grid layouts, and user experience. 

> **⚠️ Project Status & Scope (Honest Disclaimer):**
> Please note that this repository contains **only the UI/Frontend code**. 
> * There is currently no backend, database, or server-side logic attached. 
> * Form submissions (like the Login page) use anchor tags to simulate navigation for presentation purposes[cite: 2].
> * The data displayed in tables and student cards is static dummy data[cite: 1, 4].
> * Some tabs (like Quizzes and Attendance) are empty placeholders intended for future backend integration[cite: 3].

## ⚡ Technologies Used
*   **HTML5:** Semantic structure and page layouts.
*   **Bootstrap 5 (CDN):** For the styling, and interactive components.
